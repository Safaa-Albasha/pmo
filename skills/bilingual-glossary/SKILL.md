# PMI glossary / قاموس مصطلحات إدارة المشاريع

## Status words / كلمات الحالة
Green · Amber · Red = أخضر · كهرماني · أحمر — On track · At risk · Off track = ضمن المسار · معرّض للخطر · خارج المسار.

Numbers: keep Western digits (0–9) in Arabic text unless the user asks for Arabic-Indic digits; put the currency code or symbol after the number (e.g. 537,500 ر.س).
